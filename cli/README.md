# motion-studio CLI: two-engine media seam, handoff and mix

Requires Node 22+, ffmpeg, ffprobe, and Chromium. Develop with Bun 1.4.0. Install with `npm install`, then run `npm run build`. For a packaged install, run `npm pack` and install the tarball in a project.

This first CLI slice supports `render <project.json>`, `stitch <project.json>`, and `still <project.json> <shot-id> [local-frame]`. Outputs live in the project's `output/` directory. `still` renders a PNG at the given zero-based shot-local frame (default 0). `render` creates video-only FFV1 Matroska clips and a `render.json` timing report. `stitch` checks the clips and creates the video-only master. `handoff` and `mix` are described below.

The project JSON has `fps` (24, 25, 30 or 60), `width`, `height`, `beatsSeconds`, `wordsSeconds`, and contiguous `shots`. Each shot has an `id`, `engine` (`remotion` or `hyperframes`), `start` and `end` frames (half-open), and a project-relative `entry`. Remotion shots also name their `composition`. Remotion composition dimensions, frame rate and duration must equal the project and shot range. HyperFrames compositions set their dimensions and duration in HTML. Beat and word seconds round to the nearest frame, with `Math.round` on exact ties. See `fixtures/two-engine/project.json` for a working example.

Both engines produce PNG frame sequences, then ffmpeg encodes the same lossless FFV1/yuv444p/BT.709 intermediate. The CLI requires a successful render marker for stitching and invalidates it before every rerender. A failed rerender cannot stitch stale clips. A test-only `MOTION_STUDIO_CHILD_TIMEOUT_MS` overrides the 120-second subprocess timeout. The CLI verifies frame count, dimensions, color tags and ordered presentation timestamps in both clips and the stitched master. Matroska timestamps have millisecond precision, so checks allow 0.6 ms rounding error. Engine audio is not included. The fixture includes one OFL-licensed IBM Plex Sans local font and the same color patch in both compositions; the font license is in `fixtures/two-engine/fonts/OFL.txt`.

`handoff <project.json> <shot-a> <shot-b>` checks a handoff from shot A to the shot that directly follows it. It needs a successful render and stitch. It decodes shot A's last frame and shot B's first frame through their color tags to RGB and area-averages each onto a fixed 32x32 cell grid. Two fixed thresholds apply: structure (the worst cell's mean absolute RGB difference, limit 0.15) and color (the largest per-channel change of the frame's mean color, limit 0.02); both run from 0 to 1. It then applies the same limits to the master frames on each side of the cut, and to each master frame against its shot frame, so an encoded color jump in the stitched master fails. It writes `handoff-<a>-<b>.json` (status `match`, `mismatch` or `encoded-color-jump`) and `handoff-<a>-<b>.png` (the two master frames at the cut), and exits non-zero on a mismatch or jump.

`mix <project.json>` owns the film audio. It needs a successful render and stitch, and a `mix` section in the project: `{"track": "<path>", "sfx": [{"id": "<id>", "file": "<path>", "frame": <event frame>}]}`, with project-relative paths. It converts every source to 48 kHz stereo and trims or pads the track to the film. It places each SFX so that its largest absolute sample lands on the first sample of its event frame; lead-in before frame 0 and tails after the end are cut. It sums the SFX with the track, measures integrated loudness (ffmpeg `ebur128`) and applies one gain to reach -14 LUFS. The mix fails if the result would clip, is silent or shorter than 400 ms, or measures outside -14 +/- 0.5 LUFS. It writes `mix.wav` (PCM 24-bit), `final.mkv` (the master video, stream-copied, with that audio) and `sync.json`: SFX peak-to-event offsets and cut-to-beat offsets in frames (fractional; a cut is compared with the nearest beat at its unrounded frame position), the gain and the integrated LUFS. A failed mix removes earlier mix outputs. `render` and `stitch` do not remove mix outputs, so run `mix` again after either.

`fixtures/handoff/project.json` reuses the two-engine sources: its Remotion shot slides the HyperFrames title into place, so the handoff matches. The `fixtures/two-engine` shots meet at a text cut, so a `handoff` check on them reports a mismatch. Its `mix` places a pulse on the cut at frame 6. `fixtures/two-engine/audio/generate.sh` regenerates the audio fixtures with ffmpeg; the script lists their construction.

Run `npm run typecheck` and `npm test` (it builds and packs first, then runs the suite under the Node and Bun test runners) for the process-level fixture checks under both Node and Bun. Remotion's company license is required for companies with more than three people.
