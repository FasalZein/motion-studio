# paper-collage

Status: **untested until used**. This is a starting direction, not a fixed brand kit.

- Palette (example hex): Cream `#F1E8D6`, charcoal `#232221`, vermilion `#CE553E`.
- Type pairing (free fonts): Fraunces (display) + DM Sans (labels). Pin local Google Fonts files. Keep the product's verified type when it carries brand identity.
- Nearest HyperFrames frame preset: `none (the listed presets use designed paper surfaces but not cut-paper assembly).`. Presets guide composition only; copy no preset brand values into a verified product identity.
- Motion signature: `mask-line-reveal`, `shape-morph`, `cut`. Move cutout pieces as physical layers. Check ids against the `motion-vocabulary` skill when writing a storyboard.
- Variation axis 1: Paper edge: clean scissor or torn texture. Set one concrete value for this product.
- Variation axis 2: assembly: stacked evidence or one unfolding illustration.. Set one concrete value for this product.
- HyperFrames feasibility: HyperFrames: layered SVG cutouts and texture masks; GSAP transforms with stable z-order.
- Remotion feasibility: Remotion: deterministic paper-layer positions, crop masks and limited texture overlays.
- Look-specific pattern addition: Stock sticker scatter → product-specific cutouts arranged to explain the claim.
