# brutalist-mono

Status: **untested until used**. This is a starting direction, not a fixed brand kit.

- Palette (example hex): Ink `#111111`, paper `#F0ECE5`, hard accent `#E85D26`.
- Type pairing (free fonts): Barlow (heavy display) + IBM Plex Mono (small labels). Pin local Google Fonts files. Keep the product's verified type when it carries brand identity.
- Nearest HyperFrames frame preset: `broadside (nearest flat, hard-edged high-contrast type plane).`. Presets guide composition only; copy no preset brand values into a verified product identity.
- Motion signature: `cut`, `mask-line-reveal`, `flood`. Use hard edges to put the claim first. Check ids against the `motion-vocabulary` skill when writing a storyboard.
- Variation axis 1: Contrast mode: black-on-paper or paper-on-black. Set one concrete value for this product.
- Variation axis 2: type mass: one huge word or a stacked short claim.. Set one concrete value for this product.
- HyperFrames feasibility: HyperFrames: flat DOM color planes and oversized clipped typography; GSAP one-axis transforms.
- Remotion feasibility: Remotion: deterministic hard-edge SVG planes and per-frame type masks.
- Look-specific pattern addition: Full-frame slogan without proof → bold claim beside one concrete product detail.
- Public reference (direction only, not an asset license): https://en.wikipedia.org/wiki/Brutalist_architecture

Apply all pairs in [shared patterns](../patterns.md) as well.
