# swiss-grid

Status: **untested until used**. This is a starting direction, not a fixed brand kit.

- Palette (example hex): Paper `#F3F0E8`, ink `#171717`, signal red `#D32F2F`.
- Type pairing (free fonts): Archivo (display) + IBM Plex Mono (labels and numbers). Pin local Google Fonts files. Keep the product's verified type when it carries brand identity.
- Nearest HyperFrames frame preset: `broadside (nearest rigid flat typography; adapt its orange and type to the grid).`. Presets guide composition only; copy no preset brand values into a verified product identity.
- Motion signature: `mask-line-reveal`, `cut`, `push-in`. Let rules and alignment carry the change. Check ids against the `motion-vocabulary` skill when writing a storyboard.
- Variation axis 1: Grid density: wide 3-column or dense 6-column. Set one concrete value for this product.
- Variation axis 2: signal use: single index marker or a whole data row.. Set one concrete value for this product.
- HyperFrames feasibility: HyperFrames: CSS grid and clipped text layers; animate grid position without changing label order.
- Remotion feasibility: Remotion: compute columns from layout props per format; reveal rules and type with frame-driven masks.
- Look-specific pattern addition: Floating labels without alignment → labels anchored to a visible column or baseline.
- Public reference (direction only, not an asset license): https://en.wikipedia.org/wiki/International_Typographic_Style

Apply all pairs in [shared patterns](../patterns.md) as well.
