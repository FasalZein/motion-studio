# Shared template replacements

Apply every pair to every look. A look may add pairs in its own file; it cannot remove these. Replace the pattern when it is an unmotivated default. An intentional use needs a stated reason tied to the message.

| Template pattern | Replacement |
| --- | --- |
| Centered text on a gradient | An asymmetric layout on the look's canvas |
| Uniform fade-in | `mask-line-reveal` or `shape-morph` |
| Crossfade | A cut on the beat or `shape-morph` |
| Blur-in | Mask reveal |
| Glow and particle filler | One accent used with purpose |
| Logo-only outro | An end card that carries the claim and the mark |
| Reversing camera moves | One camera move per beat |

F1 in the taste research identifies the repeated default layout, type and fade as a source of sameness. F3 identifies decorative effect stacks as cheap filler. The replacements give each visual change a subject and a cause. Genre playbooks own timing bounds and holds; this list does not set durations.
