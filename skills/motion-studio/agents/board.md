# Board phase

Inputs: approved `BRIEF.md`, hero ledger, look choice, `storyboard.json` (with the `audio` beat grid), genre playbook, and `motion-vocabulary`. Output: beat map, per-shot storyboard entries, requested local still frames.

1. Analyze the real track. Run `motion-studio beats films/<slug>`: it writes BPM, beat, downbeat and drop frames and a confidence into `storyboard.json` `audio`, and the proposal in seconds to `audio/beats.detected.json`. Show the creator the result and each low-confidence reason. `grid: none` (silence or no beats), `downbeats: none` (ambiguous meter) and `drops: none` are answers, not gaps to fill by guessing. Invite corrections: edit a copy of the proposal and run `motion-studio beats films/<slug> --corrected <file>`; a grid from a DAW or another tool goes in with `--imported <file>`. With voice, derive word timing and align reveals to words while placing cuts on beats. If no track, import a voice-led manual grid. Seconds become frames with `round(seconds * fps)`. Without the CLI, use `npx hyperframes beats <hyperframes-project> --json` for beats and BPM only and record downbeats and drops by hand. Completion: `audio.grid` is `detected` with the creator's approval, `corrected` or `imported`, and word timing sources are explicit.
2. Write a beat map table: beat/frame/time, visual event, camera, spoken line, sound cue and engine. Name camera, transition and timing moves in `motion-vocabulary` terms; prefix genuinely new terms with `custom:`. Use the chosen playbook's timing bounds and evidence requirements. Completion: every beat has a visual intent or an intentional documented hold.
3. Partition the timeline into gap-free half-open shots. Select HyperFrames for HTML/GSAP or catalog motion; select Remotion for React/component-led shots. Record **why** per shot in the beat map. Switch engines at a cut unless an actual rendered-frame handoff will be checked. Assign entry, exit and local still frames, at least one still per beat, plus entry and final in-range frame. Mark protected text/logo/UI and its layout inputs. Completion: every shot's entrypoint, asset ids and still-frame requests are defined in `storyboard.json`.
4. Dispatch keyframe builders for the chosen engines and request real stills for all formats at key moments; preserve the selected candidates for G2. At G2 present the table and one still per beat, not just a text plan. Completion: the beat map and engine-rendered G2 still paths are ready for a gate decision (CLI: `motion-studio stills`, #7).
