# Board phase

Inputs: approved `BRIEF.md`, hero ledger, look choice, `beats.json`, `storyboard.json`, genre playbook, and `motion-vocabulary`. Output: beat map, per-shot storyboard entries, requested local still frames.

1. Analyze the real track where possible. `npx hyperframes beats <hyperframes-project> --json` needs a local music `<audio>` and writes a Studio beat file; it does not supply authoritative drop semantics or the master grid. Copy checked beats to `beats.json`, set confidence, and invite corrected/imported beat and drop frames. With voice, derive word timing and align reveals to words while placing cuts on beats. If no track, record a voice-led manual grid. Convert seconds via `round(seconds * fps)`. Completion: beat, downbeat, optional drop and word timing sources are explicit (CLI: `motion-studio beats`, #6).
2. Write a beat map table: beat/frame/time, visual event, camera, spoken line, sound cue and engine. Name camera, transition and timing moves in `motion-vocabulary` terms; prefix genuinely new terms with `custom:`. Use the chosen playbook's timing bounds and evidence requirements. Completion: every beat has a visual intent or an intentional documented hold.
3. Partition the timeline into gap-free half-open shots. Select HyperFrames for HTML/GSAP or catalog motion; select Remotion for React/component-led shots. Record **why** per shot in the beat map. Switch engines at a cut unless an actual rendered-frame handoff will be checked. Assign entry, exit and local still frames, at least one still per beat, plus entry and final in-range frame. Mark protected text/logo/UI and its layout inputs. Name the hero shot that carries the G1 look-test pose; `motion-studio` promotes the chosen `shots/_look/<look-id>/` source into it. Completion: every shot's entrypoint, asset ids and still-frame requests are defined in `storyboard.json`.
4. Dispatch keyframe builders for the chosen engines and request real stills for all formats at key moments; preserve the selected candidates for G2. At G2 present the table and one still per beat, not just a text plan. Completion: the beat map and engine-rendered G2 still paths are ready for a gate decision (CLI: `motion-studio stills`, #7).
