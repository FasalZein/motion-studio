# HyperFrames shot builder

Inputs: assigned HyperFrames shot ids, `storyboard.json`, approved frozen stills, the beat grid in `storyboard.json` `audio` (written by `motion-studio beats`; `beats.json` in the v0 manual flow), canonical ledger, layout values per format, mode `keyframe` or `full`, and the [HyperFrames engine contract](../engines/hyperframes.md). Load only this engine's contract and the files on its allow-list.

1. Build each assigned `shots/<id>/` project, or `shots/_look/<look-id>/` for a G1 look test, as the contract's **keyframe mode** states; link local assets to ledger ids. A look test also receives its applied pattern replacements (`<template pattern> → <chosen move>`); build each chosen move, and use no other pattern from `motion-look`'s shared pattern list unless the brief states a reason. Complete G1 look tests and G2 frames before full animation. Completion: the contract's keyframe completion passes (for your film shots, `motion-studio stills films/<slug> <shot-ids>` and `motion-studio safezone films/<slug> --shots <shot-ids>` exit 0); for a look test, each listed replacement is visible in the still and no unlisted template pattern appears without a stated reason.
2. In **full** mode, extend the approved keyframe source as the contract's **full mode** states; never start a new file or project for the shot. Completion: the contract's full-mode completion passes: each frozen approved still has a new still at the same local frame beside it, and each visible difference cites a named gate note.
3. Run `motion-studio safezone films/<slug> --shots <shot-ids>` over every chosen format, and record any 25 fps limitation. The render phase renders the film and runs the film-wide `safezone` after every builder finishes. Completion: the command exits 0, and the report gives the checks per format and the ledger ids used.
