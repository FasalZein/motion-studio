# HyperFrames shot builder

Inputs: assigned HyperFrames shot ids, `storyboard.json`, approved frozen stills, the beat grid in `storyboard.json` `audio` (written by `motion-studio beats`; `beats.json` in the v0 manual flow), canonical ledger, layout values per format, mode `keyframe`, `blocking` or `full`, and the [HyperFrames engine contract](../engines/hyperframes.md). Load only this engine's contract, the files on its allow-list and these `motion-direction` files: `reference/beat-contract.md`, `reference/seams-and-in-betweens.md`, `reference/living-holds.md` and `reference/choreography.md` for film shots, plus `reference/world-and-camera.md` in blocking mode (camera paths); `reference/world-and-camera.md`, `reference/seams-and-in-betweens.md`, `reference/living-holds.md` and `reference/choreography.md` for a look test. Add `reference/product-ui.md` for a shot with product UI and `reference/2d-and-3d.md` for a shot that declares `threeD`.

Build motion, not poses. Every beat moves as its motion event and camera state; every hold is a living hold (camera drift, parallax, light, type or UI behavior keeps moving) that stays inside the D59 liveness limits in `reference/living-holds.md`. Product UI is a live object rebuilt in code from its captured state and animated as behavior, never a pasted screenshot.

1. Build each assigned `shots/<id>/` project, or `shots/_look/<look-id>/` for a G1 look test, as the contract's **keyframe mode** states; link local assets to ledger ids. A look test also receives its applied pattern replacements (`<template pattern> → <chosen move>`); build each chosen move, and use no other pattern from `motion-look`'s shared pattern list unless the brief states a reason. Complete G1 look tests and G2 frames before full animation. Completion: the contract's keyframe completion passes (for your film shots, `motion-studio stills films/<slug> <shot-ids>` and `motion-studio safezone films/<slug> --shots <shot-ids>` exit 0); for a look test, each listed replacement is visible in the still and no unlisted template pattern appears without a stated reason.
2. In **blocking** mode (after G2), extend the approved keyframe source as the contract's **blocking mode** states: every beat moves with its real timing, camera path, seam thread and living holds at placeholder fidelity, in the approved layout; never start a new file or project for the shot. Completion: the contract's blocking completion passes for your shots (approved poses kept at the G2 still frames, every beat and hold moves, `safezone --shots` exits 0, `repro` for a `threeD` shot).
3. In **full** mode (after G3), extend the blocking source as the contract's **full mode** states; never start a new file or project for the shot. Completion: the contract's full-mode completion passes: each frozen approved still has a new still at the same local frame beside it, and each visible difference cites a named gate note.
4. Run `motion-studio safezone films/<slug> --shots <shot-ids>` over every chosen format, and record any 25 fps limitation. The render phase renders the film and runs the film-wide `safezone` after every builder finishes. Completion: the command exits 0, and the report gives the checks per format and the ledger ids used.
