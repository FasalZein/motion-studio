# Remotion shot builder

Inputs: assigned Remotion shot ids, `storyboard.json`, approved frozen stills, the beat grid in `storyboard.json` `audio` (written by `motion-studio beats`; `beats.json` in the v0 manual flow), canonical ledger, format layouts, mode `keyframe` or `full`, and the [Remotion engine contract](../engines/remotion.md). Load only this engine's contract, the files on its allow-list and these `motion-direction` files: `reference/beat-contract.md`, `reference/seams-and-in-betweens.md`, `reference/living-holds.md` and `reference/choreography.md` for film shots; `reference/world-and-camera.md`, `reference/seams-and-in-betweens.md`, `reference/living-holds.md` and `reference/choreography.md` for a look test. Add `reference/product-ui.md` for a shot with product UI and `reference/2d-and-3d.md` for a shot that declares `threeD`.

Build motion, not poses. Every beat moves as its motion event and camera state; every hold is a living hold (camera drift, parallax, light, type or UI behavior keeps moving) that stays inside the D59 liveness limits in `reference/living-holds.md`. Product UI is a live object rebuilt in code from its captured state and animated as behavior, never a pasted screenshot.

1. Build each assigned `shots/<id>/` project, or `shots/_look/<look-id>/` for a G1 look test, as the contract's **keyframe mode** states. Pin fonts and use props for each layout. A look test also receives its applied pattern replacements (`<template pattern> → <chosen move>`); build each chosen move, and use no other pattern from `motion-look`'s shared pattern list unless the brief states a reason. Completion: the contract's keyframe completion passes (for your film shots, `motion-studio stills films/<slug> <shot-ids>` and `motion-studio safezone films/<slug> --shots <shot-ids>` exit 0); for a look test, each listed replacement is visible in the still and no unlisted template pattern appears without a stated reason.
2. In **full** mode, extend the approved keyframe component as the contract's **full mode** states; never start a new component or project for the shot. Apply UI polish rules only to product UI inside the shot. Completion: the contract's full-mode completion passes: each frozen approved still has a new still at the same local frame beside it, and each visible difference cites a named gate note.
3. Run `motion-studio safezone films/<slug> --shots <shot-ids>` over every chosen format. The render phase renders the film and runs the film-wide `safezone` after every builder finishes. Completion: the command exits 0, and the report gives the checks per format and the ledger ids used.
