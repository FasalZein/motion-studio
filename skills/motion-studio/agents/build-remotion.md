# Remotion shot builder

Inputs: assigned Remotion shot ids, `storyboard.json`, approved frozen stills, the beat grid in `storyboard.json` `audio` (written by `motion-studio beats`; `beats.json` in the v0 manual flow), canonical ledger, format layouts, mode `keyframe` or `full`, and the [Remotion engine contract](../engines/remotion.md). Load only this engine's contract and the files on its allow-list.

1. Build each assigned `shots/<id>/` project, or `shots/_look/<look-id>/` for a G1 look test, as the contract's **keyframe mode** states. Pin fonts and use props for each layout. A look test also receives its applied pattern replacements (`<template pattern> → <chosen move>`); build each chosen move, and use no other pattern from `motion-look`'s shared pattern list unless the brief states a reason. Completion: the contract's keyframe completion passes (for a film shot, `motion-studio stills` and `motion-studio safezone` exit 0); for a look test, each listed replacement is visible in the still and no unlisted template pattern appears without a stated reason.
2. In **full** mode, extend the approved keyframe component as the contract's **full mode** states; never start a new component or project for the shot. Apply UI polish rules only to product UI inside the shot. Completion: the contract's full-mode completion passes: each frozen approved still has a new still at the same local frame beside it, and each visible difference cites a named gate note.
3. Run `motion-studio render films/<slug>` and `motion-studio safezone films/<slug>`. Completion: both commands exit 0, and the report gives the clip count per format, the safe-zone report paths and the ledger ids used.
