# Asset phase

Inputs: `BRIEF.md`, `storyboard.json`, `ledger.json`, project root and mode `hero` or `fill`. Output: frozen files under `assets/`, updated canonical `ledger.json` and a rights-gap report.

1. In **hero** mode, gather only the track or voice/script, real logo, local font files, palette and product screenshots needed for G1. For a product URL, `npx hyperframes capture <URL> -o <output>` captures site pixels and extracted tokens; verify the saved copy and source URL. Record the original page's claims and retrieval date; do not treat inferred marketing copy as fact. Website capture command requires its installed CLI reference before use. Completion: G1 tests can use real branded inputs.
2. For HeyGen catalog music, SFX, images and icons, use `npx hyperframes media-use resolve --type <type> --intent "<need>" --project <shot-project>` after checking `--candidates`; copy/link the frozen result into `assets/` and import its `.media/manifest.jsonl` provenance into `ledger.json` (CLI: `motion-studio assets`, #10; HeyGen import #11). `--doctor` checks readiness; if the provider is absent, report the gap and use approved alternative sources. Logo resolver uses official sources, not a HeyGen catalog logo guarantee. A resolved file is **not** proof of publishing rights.
3. In **fill** mode, source real SFX for each event and measure peak offset; look for suitable stock on Mixkit or Pexels, and pin font files from Google Fonts with their license text. Make SVG/canvas/shader assets in code when they are a better fit. Use AI-generated stills only if a provider is available; ask before paid generation. For data stories, link every displayed value to the source URL, retrieved date and field. Completion: every used file has one ledger id and source evidence.
4. Each `ledger.json` entry records `{id,type,sourceKind,sourceUrlOrGenerator,providerAssetId,license:{status,name,evidence},localPath,sha256,shots}`. `sourceKind` is `heygen|website|stock|code|ai-image|data` (`video-model` is reserved). License `status` is `known|unknown|restricted`; a known license needs its name and evidence. Use `unknown` where catalog terms or source rights were not verified. On failure, add no partial entry. Completion: all shot asset references resolve to hashed local files and a report lists unknown/restricted rights for D37 before G5.
