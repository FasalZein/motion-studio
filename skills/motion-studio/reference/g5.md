# G5 drafts, delivery check and file acceptance

Load this packet when G4 is approved and G5 is pending, noted or stale, or when `status` names final delivery or file acceptance.

## Drafts and loop B

1. Load `agents/render.md`. Build any named format adaptations at their own layouts, not by cropping another format. Run `render`, `stitch`, `handoff`, `mix`, `safezone`, `scan`, `liveness` on every changed format, then `motion-studio deliver films/<slug> --quality draft`. Draft encoding is H.264 CRF 23 / veryfast with AAC 192 kbps, 48 kHz stereo; it does not change engine-render fidelity. Completion: every chosen format has a playable current draft, poster and sheets.
2. Run `packet films/<slug>` on these masters. Run loop B using [g4.md](g4.md)'s **Full pass and loop A** steps 3-4 with the stage labeled B. Review the actual mixed drafts and their audio, not only sheets or a builder's handoff. Keep B's own three-loop budget per revision and preserve A's reports. Stop at all applicable scores at least 8 with no required judgment unverified, or after three loops. At the limit show all deltas and offer accept at current scores, notes or rescope. Completion: calibrated current B reports and score records exist; the user sees any exhausted budget.

## Present G5

Run `status films/<slug>` and `assets films/<slug> list`. Show, for each chosen format:

- `renders/<format>/draft.mp4` and `poster.png`.
- `renders/<format>/contact-sheet-*.png` and `safezone.json`, including every failure and unavailable measurement.
- Current `liveness.json`, scan and sync reports, current loop B scorecard and unresolved findings. G5 binds liveness live (D72); a changed report requires G5 again.
- For `ui-morph-loop`, `delivery/draft/<format>/loop.json`, repeated picture playback and the audible seam. Loop measurements are advisory, not proof of a seamless loop.
- Each unknown or restricted ledger license, its asset id, evidence and intended use. Ask for a written acknowledgment for **each** asset, or replace it with a licensed file. Acceptance does not relabel an asset as licensed.
- Final-render cost: explain local final encoding (H.264 CRF 16 / slow, AAC 192 kbps), expected compute time and any monetary cost. `deliver` encodes existing full-resolution masters; it does not buy assets or rerender engines. Ask for explicit cost approval; `use defaults` alone does not supply a license reason or consent to an unstated cost.

**The director-builder stops before `gate G5 approve`.** Wait for the user's explicit decision after showing the G5 artifacts. Silence is not approval.

Offer approve, changes with named defects, or rescope; state note rounds used out of 3. Record the decision with `motion-studio gate films/<slug> G5 <approve|changes|rescope> --note "<user words>"`. For notes run `taste notes films/<slug> G5` and follow the skill's Notes section. An empty `critique[]` warning is not a completed loop B. Completion: G5 is approved and current; every rights decision and cost consent is explicit. Changes to source, ledger, layout or live liveness require G5 again.

## Final bundle and acceptance

After the user's cost and rights decisions, run:

```sh
motion-studio deliver films/<slug> --quality final --cost-note "<director's cost approval>" --ack-license <asset-id> "<director's reason>"
```

Repeat `--ack-license <id> "<reason>"` for every unknown or restricted entry; omit it when none remain. The command refuses missing approvals, missing cost consent, unresolved rights without reasons, stale sources, a mux that does not match its master and mix, or a live final mux whose hash differs from G5's recorded hash (present G5 again). It verifies MP4 codecs, canvas, fps, frame count and audio, then bundles each format's MP4, poster, sheets, loop measurements when needed, ledger and `SOURCE-README.md` under `delivery/final/`. `manifest.json` records cost approval, license acknowledgments and exact file hashes. Source files remain in the original film folder; the README explains their paths.

Show the actual final files. Request **file acceptance**, separately from G5 and cost approval. After the user accepts, run `motion-studio accept films/<slug> --note "<user's words>"`. It verifies the current approvals, film inputs and bundle hashes and records acceptance in the manifest. Run `status` again: it advances from final render to acceptance, then to `delivery complete`. A changed source, master, mix or bundle makes that receipt stale; repeat the affected checks and delivery before acceptance. Record taste with `taste accept` only after actual file acceptance.

Completion: the user accepted the actual files, `status` reports the accepted bundle current, and every license acknowledgment and cost approval remains in `delivery/final/manifest.json`.
