# G4 full build and presentation

Load this packet when G3 is approved and G4 is pending, noted or stale. You remain director-builder. A fresh critic reviews; the user decides the gate.

## Full pass and loop A

1. Load `agents/assets.md` mode `fill`, then each shot's engine builder brief mode `full`. Extend the approved blocking with ledger assets. Keep real captures as hero material (D78); use Remotion for built UI from brand tokens (D81). Run `motion-direction/reference/polish.md` before G4. Completion: each shot meets its full-build and polish checks, or records why an item does not apply.
2. Use the `motion-score` output from the Score phase after Blocking and before Animatic. Load that skill to revise it when the full build changes cues, timing, descriptions, camera, transitions or timed moves. Entry/exit flags and unrelated visual effects do not require a rescore. The refusal names the failed score condition. A reused or unchosen bed is a defect. Require its timing, loudness, true-peak and deterministic-output checks to pass before mixing. Load `agents/render.md` steps 2-7. For every chosen format, run `render`, `stitch`, `handoff`, `mix`, `safezone`, `scan`, `liveness`, then `deliver films/<slug> --quality draft`. `deliver` makes the playable full-pass MP4, poster and sheets. Repair technical blockers before review; regenerate every check after a changed master. Completion: `renders/<format>/draft.mp4` plays with sound and each format has current reports.
3. Run `motion-studio packet films/<slug>` and load `motion-critique` steps 2-4. Dispatch a fresh independent critic with only the packet paths, current revision, format list, loop number, rubric and `critique/loop-<n>.md` destination. The critic scores the neutral calibration cases first. Run `motion-studio calibrate <scores.json> <motion-critique>/evals/calibration-bands.json` before its film scores count. A failed calibration voids that review; dispatch a fresh critic. Save each report, including its independence label and a `Packet:` header line with each format's current master SHA-256. Record supported scores and findings in `storyboard.json` `critique[]` with the revision hash; list unverified judgments in the report, never convert them to scores. Completion: every format has a current report and calibration passed.
4. Give the builder only the three worst findings. Repair their named shots; repeat step 2, regenerate packets and use a fresh critic each loop. Keep a loop ledger in `critique/loops.md`: A or B, revision, loop count, report path, calibration result, scorecard and deltas. Use globally increasing report numbers so loop B preserves loop A. Stop A after three reviews per revision, or when every applicable score is at least 8 and no required judgment remains unverified. A repair alone does not reset the count; notes or rescope must establish a new revision. Completion: the stop condition and every score delta are recorded.

A liveness pass is a technical condition, not the quality bar. Camera drift alone can pass it. A handoff `match` proves its measured seam conditions, not composition, truthful UI behavior or craft. The critic must inspect readable full-rate motion, real sound, hierarchy, brand and result reveals; unavailable playback stays unverified.

## Present, then stop

Run `motion-studio status films/<slug>` and show real artifacts in one message, per format:

1. Playable full pass: `renders/<format>/draft.mp4` and its actual frame count and canvas.
2. Current critic's `critique/loop-<n>.md`, independence label, film and shot scorecards, unresolved judgments, and the score deltas from every loop.
3. `renders/<format>/liveness.json`: content-basis moving share, whole-film share, each failed limit and located still span. Explain repairs and remaining defects.
4. Human listen: play the current draft with sound. Ask all five questions in `motion-score` `SKILL.md` and use its one-parameter-per-answer map. Save exact answers in `audio/scores/<revision>/listening.md`; show the score report and remaining sound defects. Rescore, import, mix and deliver again after a change. The critic’s audible judgment stays unverified without actual listening.
5. Choices: **approve / accept at current scores**, **changes / give notes**, or **rescope**. State the loops used out of 3 and note rounds used out of 3. At the loop limit, ask the user now; start no fourth review.

**The director-builder stops before `gate G4 approve`.** Wait for the user's listening answers and gate decision. Silence is not approval. G4 needs a current playable draft and master-bound `draft.json` proof per format (rerun `deliver --quality draft` after a changed master), plus current passing liveness per format; only the director can waive it with a written reason: `gate films/<slug> G4 approve --waive liveness --note "<reason>"`. A harness without independent subagents labels every review non-independent; the director must explicitly waive independence with `--waive critique --note "<reason>"`. The current packet and report remain required (D80). Neither waiver raises a score. Every film also needs a current passing original-score report, unchanged imported WAVs, an import receipt naming `audio.track`, and non-empty `listening.md` for that revision. For a deliberately chosen licensed track, the director must record `--waive score --note "<reason>"`; it lifts only original-score evidence, not rights or listening judgment. Changing the chosen bed makes G4 stale.

Record the exact decision with `motion-studio gate films/<slug> G4 <approve|changes|rescope> --note "<user words>"`. For notes, run `taste notes films/<slug> G4` and follow the skill's Notes section. An empty `critique[]` warning means the score record is missing even if the report exists; restore that record before claiming the loop is complete. Completion: `status` shows the user's G4 decision, with each requested waiver recorded, and no unexplained empty score record.
