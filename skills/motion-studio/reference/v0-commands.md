# v0 command substitutions

Run commands from the named project or shot directory. These are substitutions, not a claim of parity with the future CLI. `npx hyperframes` flags below come from installed `hyperframes-cli` and `media-use` references; Remotion's installed render skill documents verbs but not its argument flags. Check `npx remotion render --help` and `npx remotion still --help` locally before using flagged forms. `ffmpeg` expressions below are concrete building blocks; an operator must inspect output and supply project-specific paths, fps, dimensions and frames. No end-to-end mixed-engine command exists in v0.

| Spec command | v0 command or operation | Replacement | Verification status and limit |
|---|---|---|---|
| `init` | `mkdir -p films/<slug>/{assets,shots,stills,renders,audio,critique}`; create files using [layout](project-layout.md) | #4 | Shell shape verified; not a schema initializer. |
| `validate`, `status` | inspect `storyboard.json` and ledger manually; `jq -e . storyboard.json ledger.json`; `npx hyperframes check <shot>` for HF only | #4 | `check` flags documented; cross-project validation/status unverified. |
| `gate` | `shasum -a 256 BRIEF.md beats.json <gate-input-files>`; record each exact path/hash, decision and stale states in storyboard | #5 | `shasum` command verified; dependency propagation remains manual. |
| `beats` | `npx hyperframes beats <HF-project> --json`; inspect `beats/<audio-relative-path>.json`, then manually correct/import `beats.json` | #6 | Verified only for a local marked `<audio>` in an HF project; no drop confidence promise. |
| `stills` | `npx hyperframes check <HF-project> --at <local-seconds> --snapshots` for annotated HF frames; `npx remotion still <entrypoint> <out.png> --frame=<local-frame>` in shot dir | #7 | HF `check` flags documented; clean HF still extraction and Remotion flagged form unverified against installed CLI. |
| `animatic` | `ffmpeg -loop 1 -framerate <fps> -i <still.png> -frames:v <shot-frames> -an <shot-animatic.mkv>` per shot; stitch video then mux real track | #7 | ffmpeg building block; full assembly and exact audio duration unverified. |
| `sheet` | `ffmpeg -i <master.mp4> -vf fps=1 <sheet-%04d.png>`; extract each seam with `-vf select='between(n\,<first>\,<last>)' -vsync 0 <strip-%04d.png>` | #7 | fps filter is standard; seam frame offsets must be checked. |
| `render` | `npx hyperframes render <HF-project> --fps <24|30|60> --quality draft --output <out.mp4>`; `npx remotion render <entrypoint> <out.mp4>` from Remotion shot dir; then normalize each via ffmpeg | #2 | HF flags documented; Remotion positional form and lossless normalization unverified as an integration path. |
| `stitch` | `ffmpeg -f concat -safe 0 -i <ordered-clips.txt> -c copy <picture.mkv>` after matching stream parameters; `ffprobe -v error -count_frames -select_streams v:0 -show_entries stream=nb_read_frames -of default=noprint_wrappers=1 <picture.mkv>` | #2 | Commands are ffmpeg forms; frame-exact concatenation and timestamps must be measured. |
| `handoff`, `mix` | extract A last and B first with `ffmpeg -i <clip> -vf select='eq(n\,<index>)' -frames:v 1 <frame.png>`; inspect transition strip; `ffmpeg -i <picture.mkv> -i <master-audio.wav> -map 0:v:0 -map 1:a:0 -c:v libx264 -c:a aac -ar 48000 <draft.mp4>` | #3 | Extraction/mux forms; automatic threshold, SFX peak placement, -14 LUFS and sync report **unverified**. Measure with `ffmpeg -i <mix.wav> -af loudnorm=I=-14:TP=-1.5:LRA=11:print_format=json -f null -` and retain result; this measures, not mixes. |
| `scan` | `npx hyperframes check <HF-project> --snapshots`; `ffmpeg -i <master.mp4> -vf blackdetect=d=0.04:pix_th=0.10 -an -f null -` | #8 | HF audit and blackdetect partial; pop, ghost and intentional-cut distinction unverified. |
| `safezone` | `npx hyperframes check <HF-project> --snapshots` plus inspect exported protected bounds per format against declared safe rectangles | #9 | HF layout checks are not an equivalent safe-zone check; Remotion bounds and overlay presets unverified. |
| `assets`, `doctor` | `npx hyperframes media-use resolve --doctor`; `npx hyperframes doctor --json`; `npx hyperframes media-use resolve --type bgm --intent "<need>" --candidates --project <HF-project>` then resolve without `--candidates` | #10 | Flags documented; doctor JSON exits zero even on trouble, check `.ok`. Provider rights require separate evidence. |
| HeyGen import | `npx hyperframes media-use resolve --type <bgm|sfx|image|icon> --intent "<need>" --project <HF-project>`; read `.media/manifest.jsonl`, copy/hash file, manually append canonical ledger entry | #11 | Resolve command documented; import transformation and license proof unverified. |

For the delivery mix, first measure each SFX's peak and place it so its peak, not its file start, hits the event frame. Use 48 kHz stereo PCM as the audio master; measure the finished mix's integrated LUFS and offset report. ffmpeg `loudnorm` measurement alone does not establish -14 LUFS delivery. Store reports and actual command lines beside the bundle. A failure or unverified command blocks claims of an automated pass, not manual review.
