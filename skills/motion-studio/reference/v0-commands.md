# v0 command substitutions

Run commands from the named project or shot directory. These are substitutions, not a claim of parity with the future CLI. `npx hyperframes` flags below come from installed `hyperframes-cli` and `media-use` references; Remotion's installed render skill documents verbs but not its argument flags. Check `npx remotion render --help` and `npx remotion still --help` locally before using flagged forms. `ffmpeg` expressions below are concrete building blocks; an operator must inspect output and supply project-specific paths, fps, dimensions and frames. No end-to-end mixed-engine command exists in v0.

## Installed-CLI route: render to delivery

With the CLI installed, run these four commands in order on `films/<slug>`. Each takes an optional format (`16:9`, `9:16`, `1:1`); without one it works on every chosen format. Do not mix this route with the manual commands below: the CLI steps need the files the earlier CLI steps write.

1. `motion-studio render films/<slug>`: renders every shot clip and writes the success marker.
2. `motion-studio stitch films/<slug>`: joins the clips into the master picture on one frame clock.
3. `motion-studio handoff films/<slug>`: checks each seam declared `exit: handoff`: shot A rendered one frame past its end against shot B's first frame. A film without handoff seams prints `no handoff seams; nothing to check` and exits 0. Name a pair to check one handoff seam; a named declared cut is refused.
4. `motion-studio mix films/<slug>`: mixes track, narration (`voice`) and SFX to -14 LUFS, limits true peaks to -1 dBTP and muxes it onto each master. It ducks the track 12 dB under the spoken phrases. It refuses a `voice` whose `tts` is `null`.

Paths in `renders/<format>/` (`16x9`, `9x16`, `1x1`):

| Kind | Files | Written by |
|---|---|---|
| Intermediate | `shots/<shot-id>.mkv` (one clip per shot), `render.json` (success marker), `master.mkv` (picture only) | `render`, `stitch` |
| Delivery and checks | `final.mkv` (picture and mix), `mix.wav`, `sync.json`, `handoff-<a>-<b>.json` and `.png`, `safezone.json`, `contact-sheet-NNN.png`, `transition-<a>-<b>.png`, `sheet.json`, `scan.json`, `liveness.json` | `mix`, `handoff`, `safezone`, `sheet`, `scan`, `liveness` |

A new `render` or `stitch` deletes that format's handoff, mix and sheet files, so rerun `handoff`, `mix` and `sheet` after it. Full details: `cli/README.md`.

## Commands, with the all-manual fallback

The "without it" forms below are the all-manual fallback. Use them for a whole film without the CLI, not between CLI steps.

| Spec command | v0 command or operation | Replacement | Verification status and limit |
|---|---|---|---|
| `init` | With the CLI installed: `motion-studio init <slug>` in the working directory. Without it: `mkdir -p films/<slug>/{assets,shots,stills,renders,audio,critique}`; create files using [layout](project-layout.md) | #4 | CLI creates the layout, an empty valid `storyboard.json`, `ledger.json` and `BRIEF.md`; it never overwrites a project. |
| `validate`, `status` | With the CLI installed: `motion-studio validate films/<slug>` and `motion-studio status films/<slug>`. Without it: inspect `storyboard.json` and ledger manually; `jq -e . storyboard.json ledger.json`; `npx hyperframes check <shot>` for HF only | #4 | CLI checks schema, entrypoints, ledger ids, paths and hashes, ranges, handoff pairs, seam threads (every shot after the first needs `thread` with a thread kind and non-empty `shared` text, D64; render commands run the same check) and cuts on the beat grid (`offBeatCut` exempts a declared cut, D41); `status` still reports gates on an unfinished film. `status` recomputes gate hashes and shows stale gates with the changed inputs; `validate` fails on each stale gate; render commands skip that gate check. `validate` warns on an unknown `camera`, `transition`, effect or critique issue term; `custom:<description>` passes (#12). |
| `gate` | With the CLI installed: `motion-studio gate films/<slug> <G1-G5> <approve\|changes\|rescope> --note "<text>"` (G4 approve without a passing liveness report: add `--waive liveness` with the director's reason as the note; G4 approve also needs a fresh reviewer's `critique/loop-<n>.md` whose header `Packet:` line names the current packet and master sha256, D78; without a subagent tool, a non-independent report needs `--waive critique --note "<reason>"`, D80, which lifts only the independence requirement). Without it: `shasum -a 256 BRIEF.md beats.json <gate-input-files>`; record each exact path/hash, decision and stale states in storyboard | #5 | CLI hashes the inputs in `cli/schema/gate-inputs.json`, freezes what each gate showed in `stills/approved/<gate>-<hash8>/` and binds the approval to those copies, enforces gate order (every gate record present) and the 3-round cap, and marks later gates stale on notes. | `beatmap` | With the CLI installed: `motion-studio beatmap films/<slug>` prints the beat map table with the seam thread and the spoken line of each shot (`missing` marks a seam without a thread). Without it: list for each shot the words whose frame `voice.startFrame + round(start * fps)` falls inside `[startFrame, endFrame)` | #19 | `validate` checks that each `shots[].reveals` frame is its word's frame; without the CLI, check reveal frames by hand. |
| `stills` | With the CLI installed: `motion-studio stills films/<slug> [<shot-id>...] [--frames <n,...>] [--format <format>]` (defaults: every shot, its `stillFrames`, every chosen format). Without it: `npx hyperframes check <HF-project> --at <local-seconds> --snapshots` for annotated HF frames; `npx remotion still <entrypoint> <out.png> --frame=<local-frame>` in shot dir | #7 | CLI renders each frame through the shot's engine at each format's canvas into `stills/G2/<format>/<shot-id>-f<frame>.png` and rebuilds that folder's G2 sheet `sheet.png` with its index `sheet.json`. Stills match the rendered clip frames. `stills`, `still` and `render` refuse a frame with transparent pixels (D51; paint the background inside the composition, see the engine contracts). G1 look-test stills stay manual: save them as `stills/G1/<look-id>.png`. Manual: HF `check` flags documented; clean HF still extraction and Remotion flagged form unverified. |
| `animatic` | With the CLI installed: `motion-studio animatic films/<slug>` after G2 is approved and the blocking builds of the primary format are rendered and stitched. It prints the animatic's liveness verdict as advice and never fails on it. Manual: staleness and audio duration unverified. |
| `sheet` | With the CLI installed: `motion-studio sheet films/<slug> [format]` after `stitch`. Without it: `ffmpeg -i <master.mp4> -vf fps=1 <sheet-%04d.png>`; extract each seam with `-vf select='between(n\,<first>\,<last>)' -vsync 0 <strip-%04d.png>` | #7 | CLI writes `renders/<format>/contact-sheet-NNN.png` (frames at each whole second, 5 x 5 per page), `transition-<a>-<b>.png` for each seam (5 frames on each side of the cut at full frame rate) and the tile index `sheet.json`. | `render` | With the CLI installed: step 1 of the route above. | `stitch` | With the CLI installed: step 2 of the route above. Without it: `ffmpeg -f concat -safe 0 -i <ordered-clips.txt> -c copy -bsf:v 'setts=ts=N/(<fps>*TB):duration=1/(<fps>*TB)' <picture.mkv>` after matching stream parameters (the `setts` filter sets each frame's time from its global index; plain concat adds millisecond rounding across clips); `ffprobe -v error -count_frames -select_streams v:0 -show_entries stream=nb_read_frames -of default=noprint_wrappers=1 <picture.mkv>` | #2, #22 | CLI checks each clip, then the master's frame count and every timestamp against `index / fps`. | `handoff`, `mix` | render shot A one frame past its end (see the engine contract's handoff section), extract B first with `ffmpeg -i <clip> -vf select='eq(n\,0)' -frames:v 1 <frame.png>` and compare the two; inspect transition strip; `ffmpeg -i <picture.mkv> -i <master-audio.wav> -map 0:v:0 -map 1:a:0 -c:v libx264 -c:a aac -ar 48000 <draft.mp4>` | #3, #22 | With the CLI installed: steps 3 and 4 of the route above, on every chosen format. `mix` also places the narration at `voice.startFrame` and ducks the track under it. | `scan` | With the CLI installed: `motion-studio scan films/<slug> [format]` after step 2 of the route above; `motion-studio scan <video-file> --report <file.json>` for a standalone video. Without it: `ffmpeg -i <master.mp4> -vf blackdetect=d=0.04:pix_th=0.10 -an -f null -` finds black frames only | #8 | CLI flags pop, cell pop, stutter, hitch, flash, blank, flat, color jump and ghost in `renders/<format>/master.mkv` and writes `renders/<format>/scan.json`. | `repro` | With the CLI installed: `motion-studio repro films/<slug> <shot-id> [format]`. For the delivery mix, first measure each SFX's peak and place it so its peak, not its file start, hits the event frame. Use 48 kHz stereo PCM as the audio master; measure the finished mix's integrated LUFS and offset report. ffmpeg `loudnorm` measurement alone does not establish -14 LUFS delivery. Store reports and actual command lines beside the bundle. A failure or unverified command blocks claims of an automated pass, not manual review.
