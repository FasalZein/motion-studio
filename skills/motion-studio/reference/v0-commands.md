# v0 command substitutions

Run commands from the named project or shot directory. These are substitutions, not a claim of parity with the future CLI. `npx hyperframes` flags below come from installed `hyperframes-cli` and `media-use` references; Remotion's installed render skill documents verbs but not its argument flags. Check `npx remotion render --help` and `npx remotion still --help` locally before using flagged forms. `ffmpeg` expressions below are concrete building blocks; an operator must inspect output and supply project-specific paths, fps, dimensions and frames. No end-to-end mixed-engine command exists in v0.

## Installed-CLI route: render to delivery

With the CLI installed, run these four commands in order on `films/<slug>`. Each takes an optional format (`16:9`, `9:16`, `1:1`); without one it works on every chosen format. Do not mix this route with the manual commands below: the CLI steps need the files the earlier CLI steps write.

1. `motion-studio render films/<slug>`: renders every shot clip and writes the success marker.
2. `motion-studio stitch films/<slug>`: joins the clips into the master picture on one frame clock.
3. `motion-studio handoff films/<slug>`: checks each seam declared `exit: handoff` (skip when the film has none; name a pair to check one seam).
4. `motion-studio mix films/<slug>`: mixes track and SFX to -14 LUFS and muxes it onto each master. It refuses a film with `voice`; mix narration manually (see `agents/render.md`) until #19.

Paths in `renders/<format>/` (`16x9`, `9x16`, `1x1`):

| Kind | Files | Written by |
|---|---|---|
| Intermediate | `shots/<shot-id>.mkv` (one clip per shot), `render.json` (success marker), `master.mkv` (picture only) | `render`, `stitch` |
| Delivery and checks | `final.mkv` (picture and mix), `mix.wav`, `sync.json`, `handoff-<a>-<b>.json` and `.png`, `safezone.json`, `contact-sheet-NNN.png`, `transition-<a>-<b>.png`, `sheet.json` | `mix`, `handoff`, `safezone`, `sheet` |

A new `render` or `stitch` deletes that format's handoff, mix and sheet files, so rerun `handoff`, `mix` and `sheet` after it. Full details: `cli/README.md`.

## Commands, with the all-manual fallback

The "without it" forms below are the all-manual fallback. Use them for a whole film without the CLI, not between CLI steps.

| Spec command | v0 command or operation | Replacement | Verification status and limit |
|---|---|---|---|
| `init` | With the CLI installed: `motion-studio init <slug>` in the working directory. Without it: `mkdir -p films/<slug>/{assets,shots,stills,renders,audio,critique}`; create files using [layout](project-layout.md) | #4 | CLI creates the layout, an empty valid `storyboard.json`, `ledger.json` and `BRIEF.md`; it never overwrites a project. |
| `validate`, `status` | With the CLI installed: `motion-studio validate films/<slug>` and `motion-studio status films/<slug>`. Without it: inspect `storyboard.json` and ledger manually; `jq -e . storyboard.json ledger.json`; `npx hyperframes check <shot>` for HF only | #4 | CLI checks schema, entrypoints, ledger ids, paths and hashes, ranges, handoff pairs and cuts on the beat grid (`offBeatCut` exempts a declared cut, D41); `status` still reports gates on an unfinished film. `status` recomputes gate hashes and shows stale gates with the changed inputs; `validate` fails on each stale gate; render commands skip that gate check. Vocabulary warnings (#12) are not checked yet. |
| `gate` | With the CLI installed: `motion-studio gate films/<slug> <G1-G5> <approve\|changes\|rescope> --note "<text>"`. Without it: `shasum -a 256 BRIEF.md beats.json <gate-input-files>`; record each exact path/hash, decision and stale states in storyboard | #5 | CLI hashes the inputs in `cli/schema/gate-inputs.json`, freezes what each gate showed in `stills/approved/<gate>-<hash8>/` and binds the approval to those copies, enforces gate order (every gate record present) and the 3-round cap, and marks later gates stale on notes. Without it, propagation is manual. |
| `beats` | With the CLI installed: `motion-studio beats films/<slug>` proposes the grid from `audio.track`; correct a copy of `audio/beats.detected.json` (seconds) and run `motion-studio beats films/<slug> --corrected <file>`, or `--imported <file>` for a grid from another tool. Without it: `npx hyperframes beats <HF-project> --json`; inspect `beats/<audio-relative-path>.json`, then convert with `round(seconds * fps)` and record the grid manually | #6 | CLI gives BPM, beat, downbeat and drop frames with confidence; silence, no beats and no drop are explicit results; downbeats cover 3 and 4 beats per bar only. `hyperframes beats` gives beats and BPM only, no downbeats, drops or reliable confidence. |
| `stills` | With the CLI installed: `motion-studio stills films/<slug> [<shot-id>...] [--frames <n,...>] [--format <format>]` (defaults: every shot, its `stillFrames`, every chosen format). Without it: `npx hyperframes check <HF-project> --at <local-seconds> --snapshots` for annotated HF frames; `npx remotion still <entrypoint> <out.png> --frame=<local-frame>` in shot dir | #7 | CLI renders each frame through the shot's engine at each format's canvas into `stills/G2/<format>/<shot-id>-f<frame>.png` and rebuilds that folder's G2 sheet `sheet.png` with its index `sheet.json`. Remotion renders only the requested frames; HyperFrames renders the shot once to PNG frames (no video encode). Stills match the rendered clip frames. G1 look-test stills stay manual: save them as `stills/G1/<look-id>.png`. Manual: HF `check` flags documented; clean HF still extraction and Remotion flagged form unverified. |
| `animatic` | With the CLI installed: `motion-studio animatic films/<slug>` after G2 is approved. Without it: `ffmpeg -loop 1 -framerate <fps> -i <still.png> -frames:v <shot-frames> -an <shot-animatic.mkv>` per shot; stitch video then mux real track | #7 | CLI uses the frozen G2 stills of the primary format, shows on each frame the nearest still of its shot (switching at the midpoint between two stills, so the exit still holds up to the cut), refuses a shot without an entry (0) or exit (last frame) still, and adds `audio.track` cut to the film length into `animatic.mp4`. Narration is not added yet (#19). Manual: full assembly and exact audio duration unverified. |
| `sheet` | With the CLI installed: `motion-studio sheet films/<slug> [format]` after `stitch`. Without it: `ffmpeg -i <master.mp4> -vf fps=1 <sheet-%04d.png>`; extract each seam with `-vf select='between(n\,<first>\,<last>)' -vsync 0 <strip-%04d.png>` | #7 | CLI writes `renders/<format>/contact-sheet-NNN.png` (frames at each whole second, 5 x 5 per page), `transition-<a>-<b>.png` for each seam (5 frames on each side of the cut at full frame rate) and the tile index `sheet.json`. Manual: seam frame offsets must be checked. |
| `render` | With the CLI installed: step 1 of the route above. Without it: `npx hyperframes render <HF-project> --fps <24|30|60> --quality draft --output <out.mp4>`; `npx remotion render <entrypoint> <out.mp4>` from Remotion shot dir; then normalize each via ffmpeg | #2, #9 | CLI renders each format from its `meta.layouts` entry into `renders/<format>/shots/` and verifies frame count, size, color tags and timestamps. HF `--resolution` scales; it does not reframe. |
| `stitch` | With the CLI installed: step 2 of the route above. Without it: `ffmpeg -f concat -safe 0 -i <ordered-clips.txt> -c copy -bsf:v 'setts=ts=N/(<fps>*TB):duration=1/(<fps>*TB)' <picture.mkv>` after matching stream parameters (the `setts` filter sets each frame's time from its global index; plain concat adds millisecond rounding across clips); `ffprobe -v error -count_frames -select_streams v:0 -show_entries stream=nb_read_frames -of default=noprint_wrappers=1 <picture.mkv>` | #2, #22 | CLI checks each clip, then the master's frame count and every timestamp against `index / fps`. Manual: measure frame count and timestamps. |
| `handoff`, `mix` | extract A last and B first with `ffmpeg -i <clip> -vf select='eq(n\,<index>)' -frames:v 1 <frame.png>`; inspect transition strip; `ffmpeg -i <picture.mkv> -i <master-audio.wav> -map 0:v:0 -map 1:a:0 -c:v libx264 -c:a aac -ar 48000 <draft.mp4>` | #3, #22 | With the CLI installed: steps 3 and 4 of the route above, on every chosen format. `mix` refuses a film with `voice` until #19. Without it: extraction/mux forms only; automatic threshold, SFX peak placement, -14 LUFS and sync report **unverified**. Measure with `ffmpeg -i <mix.wav> -af loudnorm=I=-14:TP=-1.5:LRA=11:print_format=json -f null -` and retain result; this measures, not mixes. |
| `scan` | `npx hyperframes check <HF-project> --snapshots`; `ffmpeg -i <master.mp4> -vf blackdetect=d=0.04:pix_th=0.10 -an -f null -` | #8 | HF audit and blackdetect partial; pop, ghost and intentional-cut distinction unverified. |
| `safezone` | With the CLI installed: `motion-studio safezone films/<slug> [format]`. Without it: `npx hyperframes check <HF-project> --snapshots` plus inspect protected bounds per format against declared safe rectangles | #9 | CLI measures each `data-protected` element's painted pixels at its held frames in both engines (normal render against a render with the element hidden by `opacity:0`, D45) (or reads declared canvas/SVG geometry) and writes `renders/<format>/safezone.json`. Overlay presets are passed to the engines but not interpreted. |
| `assets`, `doctor` | With the CLI installed: `motion-studio doctor`; `motion-studio assets films/<slug> add <id> --file <path> --type <type> --source-kind <kind> --source <url> --license <status> [--license-name <name>] --evidence <text> [--shot <id>]...`; `motion-studio assets films/<slug> resolve <id> --provider image --type <type> --intent "<need>"`; `motion-studio assets films/<slug> list`. Without it: `npx hyperframes media-use resolve --doctor`; `npx hyperframes doctor --json`; append ledger entries by hand with `shasum -a 256 <file>` | #10 | `doctor` reports Node, ffmpeg, ffprobe, HyperFrames, Chromium, Remotion, heygen (version and sign-in) and the image provider (`MOTION_STUDIO_IMAGE_PROVIDER`); it installs nothing. `assets` checks each entry against the ledger schema, hashes the file and writes nothing on a failure; `list` shows missing or altered files and unresolved rights. HeyGen catalog search is still manual: `npx hyperframes media-use resolve --type bgm --intent "<need>" --candidates --project <HF-project>` (#11). Provider rights require separate evidence. |
| HeyGen import | `npx hyperframes media-use resolve --type <bgm|sfx|image|icon> --intent "<need>" --project <HF-project>`; read `.media/manifest.jsonl`, copy/hash file, manually append canonical ledger entry | #11 | Resolve command documented; import transformation and license proof unverified. |

For the delivery mix, first measure each SFX's peak and place it so its peak, not its file start, hits the event frame. Use 48 kHz stereo PCM as the audio master; measure the finished mix's integrated LUFS and offset report. ffmpeg `loudnorm` measurement alone does not establish -14 LUFS delivery. Store reports and actual command lines beside the bundle. A failure or unverified command blocks claims of an automated pass, not manual review.
