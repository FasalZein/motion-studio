# motion-studio

Agent skills and a CLI for directed motion-graphics films: brief, look test, beat map, storyboard stills, animatic, gated build across Remotion and HyperFrames, taste critique, and multi-format render.

Status: specification. See [docs/SPEC.md](docs/SPEC.md) and [docs/DECISIONS.md](docs/DECISIONS.md).

Remotion requires a paid company license for companies with more than 3 people. See https://www.remotion.dev/docs/license.
